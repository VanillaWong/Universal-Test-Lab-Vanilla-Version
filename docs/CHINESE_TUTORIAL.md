# Universal Test Lab 中文使用教学

> 基于 Universal-Test-Lab-Vanilla-Version（v0.12.0-beta.2 魔改版）
> 适用于《War Thunder 战争雷霆》的测试任务生成工具

---

## ⚠️ 免责声明（请先阅读）

- 本工具会**修改游戏的任务文件**，违反 War Thunder 服务条款，**使用后果自负**（建议小号测试）。
- 游戏大版本更新后，工具可能失效，请等待作者更新。
- 工具本身是开源的（MIT 协议），不包含任何破解/外挂功能。

---

## 一、这是什么？

一个帮你快速搭建**测试场景**的工具：

- 一键生成自定测试任务（地面靶场 / 飞行靶场 / 舰船 / 组合战场）
- 配置**弹药**（按武器分组，跟游戏试驾界面一致：可以给两门 30mm 机炮分别装不同弹链）
- 配置**目标**（7 个地面目标位、4 个飞行目标、舰船、ERA 预设）
- **Rapid Fire**（快速连射，主炮/机炮无后坐装填）
- **实验功能**：跨阵营换炮、弹道/机动参数微调

---

## 二、安装

1. 解压压缩包到任意目录（比如 `D:\UTL`）
2. 需要已安装 **War Thunder 游戏本体**
3. 双击运行 `UniversalTestLab.exe`
   - Windows 10 / 11 自带 .NET Framework，**无需额外安装任何运行库**
   - 如果杀毒软件报警（常见：`wt_ext_cli.exe` 被误报），请**加入信任/白名单**——这是官方开源工具，无病毒

## 三、首次使用

1. 启动后，如果弹出选择游戏目录：找到 War Thunder 安装目录（**包含 `aces.vromfs.bin` 文件的文件夹**，例如 `C:\Program Files (x86)\Steam\steamapps\common\War Thunder`）
2. 主界面顶部有 5 个标签：`VEHICLE`（载具）`TARGETS`（目标）`OPTIONS`（选项）`GARAGE`（车库）`EXPERIMENTAL`（实验）

---

## 四、VEHICLE 标签（选车 + 弹药配置）

左侧列表选车（支持搜索、按国家/权重/类型过滤：飞机/直升机/地面/舰船）。

中间是**弹药配置区**——按武器分组，复刻游戏试驾界面：

```
30mm 2A42 BMPT      [弹链下拉][数量]     0/1 chains   ← 机炮 1（每次 1 种弹链）
30mm 2A42 BMPT      [弹链下拉][数量]     0/1 chains   ← 机炮 2（可独立选弹）
130mm 9M120 ATGM    [弹1][数量][弹2][数量]   0/4 rds   ← 导弹（2 槽，总量 ≤4）
```

- **数量**可以自由输入（0 = 该槽不装弹药）
- 每行右侧显示"已分配 / 总量"，同一武器的多个槽**共享总量上限**，超出会自动裁剪
- 纯机枪车（如 M16 MGMC）会显示机枪弹链（24 条），也可以调到 0
- 顶部有预设框：保存/加载当前弹药配置

## 五、TARGETS 标签（目标与场景）

- **SCENARIO MODE**：干净测试靶场 / 组合战斗占领（选组合模式时收起到"出生点"设置）
- **ERA 预设**：下拉应用（如 WWI - 1916、WWII 等），也可以把当前配置**保存为自定义预设**
- **4 个飞行目标**：台风 / 米-28NM / 卡-52 / 主目标——各自选机型 + 数量（**0 = 不生成**）
- **7 个地面位置**：2×4 网格，可分别选目标（按国家/权重过滤），ATTACKING / PASSIVE 开关
- **舰船目标**：选舰 + 数量 + 被动/还击开关
- 配置完点 **APPLY TARGETS** 生效

## 六、OPTIONS 标签（任务选项）

- 玩家重生延迟 / 目标恢复延迟 / 地面再装填时间
- 弹药策略：无限弹药 / 有限弹药
- 出生方式：空中出生（带速度）/ 机场滑跑
- **RAPID FIRE 快速连射**：开关 + 装填间隔 + 两种模式
  - **FULL RESTORE 全量恢复**：打一发补满一发（等效无限弹药）
  - **PARTIAL RESTORE 部分恢复**：只恢复弹药数，不修车/不复活乘员
- 点 **APPLY OPTIONS** 保存

## 七、GARAGE 标签（车库）

- **RECENTLY USED 最近使用**：自动记录你选过的车，点击直接跳转
- **FAVOURITES 收藏**：★ 收藏当前车辆 / 移除
- **AMMO PRESETS 弹药预设**：把当前弹药配置存成预设、加载、删除（换车自动跟随）

## 八、EXPERIMENTAL 标签（实验功能）

- **地面车**：跨阵营/跨类型**换炮**（CANNON 选择器，可从其他坦克借炮）、弹药搜索注入、4 槽编辑器、弹道/机动调参（弹重/初速/装药/穿深/射速/后坐力/引擎功率/车重/极速）、无限弹药
- **飞机**：燃料量（滑条 + 百分比）、机枪弹链组、干扰弹站配置（带游戏内预览）
- 切车后点 **REFRESH FOR CURRENT VEHICLE**，改完点 **APPLY CONFIGURATION**

## 九、生成任务并进入游戏

1. 配置好载具 / 目标 / 选项后，在主界面点击生成按钮（GENERATE MISSION）
2. 工具会把任务文件写入游戏目录（`content/pkg_user` 下）
3. 启动游戏，进入 **测试任务**（如 Clean Test Range 干净测试靶场 / 组合战场地图）
4. 生效内容：你的载具 + 弹药配置 + 目标 + Rapid Fire 效果
   > 提示：如果游戏正在运行，生成前先退出游戏，否则文件可能被占用写不进去

## 十、常见问题

| 问题 | 解决 |
|---|---|
| 杀毒软件报毒 | `wt_ext_cli.exe` 是正常开源工具，加白名单即可 |
| 游戏更新后失效 | 等作者适配新版本（数据基于旧版本游戏提取） |
| 生成后游戏里没变化 | 确认游戏目录选择正确；先退出游戏再生成；检查目标是否设置为 0（0=不生成） |
| 弹药数量显示不对 | 多管武器（四联 M2 等）已按"弹链"显示；总弹链数 = 总备弹 ÷ 单条弹链容量 |
| 想恢复默认 | 弹药槽选 `STOCK (default ammo)` 即可用默认弹药 |

## 十一、从源码构建（可选，给开发者）

仓库：https://github.com/VanillaWong/Universal-Test-Lab-Vanilla-Version

需要 Windows + .NET Framework 4.x 编译环境：

```powershell
# 方案 1：Build.ps1（完整流程，需要游戏解包数据）
.\Build.ps1

# 方案 2：直接编译（数据已内嵌在 data/，不需要游戏数据）
& 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe' '/lib:C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF' @build.rsp
```

> 注：`universal_*_data`（游戏解包数据，约 530MB）**不包含在仓库中**，仅重跑数据生成（Build-Catalog.ps1）时需要；直接编译/直接使用 exe 不受影响。
