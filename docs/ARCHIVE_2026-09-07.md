## 2. 首个真实玩家崩溃(v0.12.0-beta.6)与热修

玩家日志(无行号,因发布包没带 PDB):

```
System.NullReferenceException
   at UniversalTestLab.MapPanel..ctor(MapPanelState state, Style toggleStylesSource)
   at UniversalTestLab.ModernMainWindow.BuildTargetsTab()
   at UniversalTestLab.ModernMainWindow..ctor()
   at UniversalTestLab.ModernUi.Run()
```

玩家环境: 全新机器(无 `%LOCALAPPDATA%\UniversalTestLab` 历史配置),Windows 8,exe 在 OneDrive 桌面。

**根因**(ModernShell.Maps.cs): 静态字段按文本顺序初始化,

```csharp
private static EraPreset[] EraPresets = LoadEraPresets();     // ← 先跑
private static readonly EraPreset[] BuiltinEraPresets = new[] {...}; // ← 还没初始化(null)
```

`LoadEraPresets()` 在没有已存 era_presets 时 `return BuiltinEraPresets` → 拿到 null →
`EraPresets` 为 null → ctor 里 `foreach (EraPreset era in EraPresets)` 抛裸 NRE
(字段直读无子帧,所以堆栈只有 ctor 一层)。开发机有历史 era_presets 配置,永远走
loaded 分支,因此从未暴露。**同类字段在 MapPanel(L174)与 ModernMapWindow(L722)各有一份,两处都改**。

**修复**: BuiltinEraPresets 声明移到 EraPresets 之前(两处),并注释原因;不能加 readonly
(`ReloadEraPresets()` 会重新赋值)。文件是 **LF 行尾**,edit_file 需用 \n。

**验证**: `Build.ps1 -SelfTest` 全绿 + **空 `--config-dir` 跑 `--uiselftest`**(模拟新玩家)
exit 0——修复前同场景即崩溃现场。

**附带改进**: `Package-Release.ps1` 现在把 `.pdb` 拷进发布 zip 并计入 SHA256SUMS;
以后玩家崩溃日志带**精确源码行号**。Release notes 为此写明了上报流程。

## 6. 玩家死后重生大调查(2026-09-07 午后,commit 38a4622/4bb8cde 已推送)

### 起因

UTL 坦克模式死后无法复活(卡死);空中出生模式多次死亡后被判"被击毁"。

### 引擎事实矩阵(全部实测/对照验证)

| 场景 | 结果 |
|---|---|
| singleMission 坦克死后(manual+unitRespawn 触发器) | ✅ 自动回地面出生点,无限(2026-09-07 修复,38a4622) |
| 空战死后,manual 无去处 | ❌ 卡在"按空格继续"(引擎空战后必经流程,压制 unitRespawn;manual 无恢复目标) |
| 空战死后 attempts/无 restoreType | ⚠️ 空格能回 1500m,但 **5 次上限**后判"飞机被击毁"(无法调高,官方无字段) |
| missionMarkAsRespawnPoint(任意格式,target 空中 area/unit) | ❌ usermission 不消费(报错"can't find any areas" 或静默无效)——多人 domination 才有重生界面 |
| type:testFlight(+descriptor/无触发器/带触发器) | ❌ usermission 直开无试驾 UI,engine 不接管(用户多次实测) |
| spawnOnAirfield(死后触发器) | ✅ 自动回跑道、无限、不卡(机场模式数周验证) |
| Ask3lad 地面死后按空格复活且"次数不消耗" | = **引擎陆战规则**(坦克死后回基地不扣 attempts),非任务机关。其 testdrive.blk 全文 3255 行通读:无 restoreType/无玩家重生触发器/无 respawn point/玩家普通 tankModels |
| 官方 test_flight_template 空中恢复 | testFlight + manual + 触发器 spawnOnAirfield/@player(需试驾 UI 上下文) |
