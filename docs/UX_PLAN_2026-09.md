## 二、界面盘点与改造项

### 1. VEHICLE 视图（主工作区）
- 现状：选车（Garage 内嵌列表已有搜索 aircraftSearch）+ 车内双工作区（Ground 弹药槽 / Aircraft 挂载）
- 痛点：弹药槽交互（Ask3lad 弹夹/容量清晰度）、挂载列表
- 改造：
  - [ ] 弹药选择/挂载武器列表 → Picker（长列表统一）
  - [ ] 弹药槽 UI 对齐 Ask3lad（_sync_ammo_slots L3431 参照——容量/约束显示）

### 2. EXPERIMENTAL 视图（GroundConfigurePanel）——**当前最乱**
- 现状一页堆：选弹（搜索框+类型+列表）| 选炮（domain/unit/cannon/round 四联动下拉）| 弹药槽 | 伪ARH/无限弹药开关 | 弹道调参 | 雷达替换（新加）
- 痛点：控件堆叠难找；四联动下拉难用；雷达区后加更挤
- 改造：
  - [ ] 四联动下拉（domain/unit/cannon/round）→ 换 Picker（一步选炮——域+单位+炮+弹 合并为一次 Picker 流/或炮 Picker 直接列全炮带宿主标签）
  - [ ] 布局分组卡片（Ask3lad QGroupBox 式）：**弹药与换弹** / **换炮（炮库）** / **雷达替换** / **弹道与开关**——每块带标题边框（SectionCard 已可用）+ 可选折叠（Expander）
  - [ ] 炮库列表 → Picker（显示宿主车/口径/弹型——解决"不认得名字"）

### 3. TARGETS 视图（ModernMapPanel）
- 现状：地图/目标配置（目标槽 + 地图下拉 + ERA 下拉 + 联合作战区）
- 痛点：地图 ComboBox（48）、目标选择、ERA
- 改造：
  - [ ] 地图选择 → Picker（地图名搜索）
  - [ ] 目标（空中/地面/舰船）→ Picker（车名搜索——VehiclePicker 同款）
  - [ ] ERA 预设下拉 → Picker/分段

### 4. GARAGE 视图
- 现状：Recently / Favourites / Presets 三列（Ask3lad Garage 同款——本身较整齐）
- 改造：小（预设命名/删除确认）——低优先

### 5. OPTIONS 视图
- 现状：语言切换 + 少量设置——已简洁——不动

### 6. 对话框族
- ModernAboutWindow（作者/开源/去 Stripe）——已更新
- ModernInputWindow（命名输入）——OK
- ModernMapWindow（现代地图编辑器——地图/出生点）——其长列表 → Picker
- ModernFlightSystemsWindow / FlightConfigure / MissionOptions / MissionGenerated——各自长列表（挂载/弹链/选项）→ 按需 Picker

## 三、交互统一原则（写入后续开发）

1. **找东西 = 搜索框**（Picker），不翻下拉
2. **一屏一主题**（分组卡/折叠），EXPERIMENTAL 带头整改
3. **选完可见**（状态行显示当前选择——雷达区已示范）
4. **可反悔**（RESET/恢复原生——雷达区已示范）
5. 列表项显示**上下文**（宿主车/口径/band——不裸显示内部名）
