## 2. 换炮问题全貌(含机制,勿再考古)

### 2.1 机制(09-02 已钉,再次实证)
- cannon 文件 = 发射机构 + 物理可装弹(容器全集,如 2A46M 含 HE/3BM9/3BM12/15/22/42)
- **引擎的弹种列表/默认弹/身份 = 车的 `weapons` 预设 + modifications 弹药包(空块,
  名字=容器)** —— 不是 cannon 文件!
- 同一 cannon 不同车能打的弹不同(16式 vs 16式FPS 教训)——可用弹按车过滤

### 2.2 UTL 换炮结构(错配根源)
```
代理 = include KVT
     + @delete commonWeapons + 重定义主炮 Weapon → donor cannon(125)   ← 只换发射器
     + weapons:t 保持 us_m1_abrams_kvt_default(105)
     + modifications(原生 105 弹药包)原样继承
```
→ 引擎列表=105(新炮无 105)→ 空槽默认 0 弹("弹药储备耗尽")、HUD/身份像 KVT、
UTL 与游戏内都选不到 125。

### 2.3 已修复(在 dist exe,部分未提交)
1. **连射不停**:生成 cannon 选单弹时曾把 cannon 裁成"纯 bullet"(无壳无 shotFreq)→
   引擎无节拍连发 + HUD 无弹量。修复=保留 cannon 壳 + 把所选弹嵌回(Generate.cs,
   `InjectedCannonRound` 裁剪分支)。KVT 场景实测:节奏恢复。
2. **弹药耗尽**:任务弹槽仍点名宿主 105 容器。修复=换炮后槽接管
   (BlkTools.ForcePlayerAmmoSlot):玩家 loadouts 中属于 donor 炮的容器优先,
   否则 **donor cannon 第一个容器**("有什么先打什么",用户拍板不要穿甲优先)。
   实测:默认打出 donor 首弹(HE),未见耗尽复报。
3. 同口径常见错配被掩盖的原因:catalog 弹列表用炮容器全集(CollectCannonContainers
   收集 donor cannon 顶层 `\d+mm_` 容器)—— 需要按"车可用子集"区分的话题用户已
   提出(2.4)。
