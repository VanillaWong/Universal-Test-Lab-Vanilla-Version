## 3. 引擎弹药机制(本轮摸清,重要)

```
① 车文件 commonWeapons：每门武器 = Weapon{ trigger, blk(炮文件), bullets:i(容量) }
   例 BMPT：gunner0/gunner7 = 双联 30mm(注意 trigger 号不连续、非槽位顺序)
② 车文件 modifications：可携带弹种 = 空块容器(+ _ammo_pack 孪生块)
③ 炮文件：容器定义(容器名 → 内含 bulletName)；顶层 bullet = "默认弹"(无容器，如 3BK12M/3BM9)
④ 任务层：bullets0..3:t = 容器名(或空=默认弹) + bulletsCount0..3 = 数量
   - 最多 4 种弹；未指定的武器 → 引擎给默认弹(不会没弹)
   - 引擎按"容器归属哪门炮"分配到对应武器
```

关键结论：
- **游戏原生只让"有弹药容器的武器"可编辑弹种**(机枪/AG-30/铜管不可编辑)；
- BMPT 显示**两组 30mm 是正常的**(游戏一致)，不要合并；
- 换炮时弹药槽受 4 种上限约束，超出部分应**提示用户**而非静默截断(待办)。
