## 1. AI 舰导弹（已闭环）

结论：**不是 bug，是 AI 专用资产没做过玩家侧调校**。

编号 | 补丁 | 作用
---|---|---
1 | `applyAllMods:b=yes` | 解锁弹药/改装件（最关键的一条）
2 | 弹药槽"导弹优先" | 枪炮占满前 4 槽会让导弹报"弹药耗尽"
3 | `special` → `rockets` | `special` 组玩家 HUD 不显示
4 | 固定发射井 `fireConeAngle=180` | 发射架不用转，导弹垂直发射
5 | `semiActive:false` | 半主动需要持续照射，玩家侧拿不到
6 | `uncageBeforeLaunch:false` | 发射前导引头笼头放开
7 | `band 9→8` | 全游戏海军雷达只有 2/5/6/8
8 | 借用 SM-6 自动驾驶 | 老式三固定增益 → 分段 PID + 比例导引
9 | **`finsAoa 0.125→0.35`、`loadFactorMax 20→24`** | **"笨拙"的直接原因**
10 | 光学导引头 `lockAngleMax 15→90`、`designation ins→radar` | HHQ-10 能捕获
11 | `ship_optical_sight` 自动补装 | 光学制导弹需要瞄具

**实测通过**：054A（HHQ-16）、Halsey（SM-2/SM-6）、052D（HHQ-9/HHQ-10）。

数值比对存档要点：
- HHQ-9 vs SM-6：163 字段中 33 不同，制导几乎全同，差在控制律与舵面权限
- HHQ-9 vs 地面 S-300：180 字段中 86 不同，共用模型但弹道独立，机动比 S-300 还低

## 2. UI 重构（本轮主战场）

### 2.1 现状诊断

- 主界面 `TabVehicleContent` **本来已是三栏**：选载具(330) / 装配(*) / 配置(330)
- 但顶部另有 4 个标签（TARGETS / OPTIONS / GARAGE / EXPERIMENTAL）**全是占位符**
  （"Stage1: migrating ..."），真正功能只存在于第一个标签和若干弹窗里
- 同一套选项存在**两份实现**：内联 `FlightConfigurePanel` 与弹窗 `ModernFlightConfigureWindow`，
  而 `EXPERIMENTAL AIRFRAME / RADAR / SHIP LOADOUT` **只在弹窗里**

### 2.2 已落地的改动

| 改动 | 说明 |
|---|---|
| 右栏改为 `SUMMARY` | 两张密集段落 → "标签 + 值"行；带滚动条 |
| 摘要内容 | 配置（弹药/燃油/弹链/改装件）+ 场景（地图/重生/目标） |
| 弹药行 | 显示**弹种名**（查 `ground_ammo.json`）+ 数量 + 总计 |

| 内联场景面板 | 地图（舰船列表/其他固定）、时间天气、出生方式+高度、目标摘要 + `编辑…` 弹窗 |
| 飞行配置内联化 | AIRFRAME / RADAR / SHIP LOADOUT 搬进内联面板，`Collect()` 同步采集 |

| 卡片紧凑行 | 实验开关改为"名称 + 右侧开关 + tooltip 说明" |

### 2.3 弹药容量（bug 修复）

用户可自由分配，但不得超上限。

**根因**：`TrimGroundLoadouts()` 这个归一化函数**从未被调用**（死代码），
读档时直接 `loadouts[slot] = entry.Copy()`，于是历史存档里的 6014 发被原样搬出来。

**四道防线**：

```
选弹种 → 按同口径剩余容量夹
改数量 → 失焦时夹
读档   → TrimToCapacity()（新增，从末槽往前扣）
写设置 → TrimToCapacity() 再夹一次
```
上限取 `vehicle.MaxAmmo`（标题那行 `120 mm • 44 rds total`）。

## 3. 设计与交互原则（本轮确立）

1. **三栏**：左选载具 / 中设置（三步）/ 右摘要
2. **弹窗只用于"选择"**：挑供体飞机、挑雷达、7 个距离位的深度编辑
3. **设置一律内联**：弹药、开关、地图、出生、目标数量
4. **右栏永远显示"我现在配了什么"**，改完立刻刷新
5. 摘要用"标签 + 值"两列，不用段落文字

## 6. 环境备忘（新增）

- 新增 `.cs` 必须手动加进 `build.rsp`，否则报 "name does not exist"
- `edit_file` 对 CRLF / `\r\r\n` 敏感，改 C# 用 Node 脚本做字节级替换
- `Regex.Replace(s,s,s,int)` 不存在；用 Regex 实例
- 编译前必须关闭 UTL，否则 `CS0016: Could not write to output file`
- 验证链：`cmd /c compile.bat` → `dist\UniversalTestLab.exe --selftest`
