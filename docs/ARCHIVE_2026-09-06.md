## 1. maxloadMass 不是挂载上限(已修复,commit e356ba4)

- FM `WeaponSlots{ maxloadMass / maxloadMassLeftConsoles / maxloadMassRightConsoles / maxDisbalance }`
  只是数据作者填的参考值,**引擎并不校验**。证据:
  - Su-33: maxloadMass=6500,但官方预设 `su_33_fab_250_270`(28×FAB-250)= **7504 kg 可正常玩**;
  - Su-27: 8040 = 官方最重方案(30×268=8040)恰相等;金鹰: 11793 ≫ 官方最重方案(~4572, mk82 snakeye)。
- 结论: 真实边界 = 每槽 WeaponPreset 白名单 + 武器质量(weapon_catalog 的 unitMass×bullets)。
  slot0 内埋炮等有 `notUseforDisbalanceCalculation:b=true`,只免不平衡计算,不是豁免总重(金鹰 slot0 有;苏-33 的 5/6/7/8 槽也有此标记)。
- UTL 修复: `ConfirmRiskyLoadout()` 超载从 throw/硬拦 → YesNo 可接受警告(注释写明依据)。`aircraft.tsv maxLoad` 仍为参考值。

## 4. 官方现代试飞模板(aircraft/ 目录)= 三件套分层

路径 `wt_mis\mis.vromfs.bin_u\gamedata\missions\training\testflight\aircraft\`:
- `test_flight_unit_template.blk` 单位池; `test_flight_template.blk` 逻辑壳(2341 行,
  `@player` / `@airfield_spawn_reload` 变量化 + descriptor fromDescriptor 注入);
  `test_flight_universal_<map>.blk` 布局壳(is_airfield_spawn 开关、armada_01 停机坪 48m 高)。
- 经典机场试飞(krymsk_jet 等): `init` 触发器 `spawnOnAirfield{runwayName:"airfield00", objects:"armada_01"}`,
  `end` 触发器(playersWhenStatus isKilled)→ wait 3s → spawnOnAirfield 重生 = **补给=跑道整机重生成**,airfields{} 为空(跑道实体来自地图)。
- `reload_missiles`(AI 无限弹的官方姿势): `unitWhenStatus{object_type:"hasMissilesInWorld"}`
  → unitSetZeroAmmo → wait 10 → `unitRestore{ammoRestore:b=true, fullRestore:b=false}`。
- `unitSetProperties{rearmTimeOnField:r=20}` = 机场补弹时间参数。
- 玩家弹药/油/修理: 官方只靠引擎机场特权 + 死后整机重生,任务层从不手动补玩家弹药(usermission 无此特权 → UTL rearm 圈是空摆设)。

## 5. 官方 addAirfield 语义(对照 UTL 修法)

官方(cta/afd 任务)用 `addAirfield{runwayStart/runwayEnd/runwayWidth(160)/army}` **不带 spawnPoint**;
spawnOnAirfield 靠 runwayName。UTL 加了 spawnPoint(必须自造跑道,Clean_Testdrive 无官方机场实体)。

## 6. 核战模式 nuclear_escalation(官方 April Fools 2026,多人 32v32)

- 玩家槽 32×2 = t1/t2_player01..32(wing 列表);mission{type:domination, customHUD:"nuclearEscalation",
  nuclearEscalationStage1:2500/Stage2:6000/Stage3:15000, afterRespawnDelaySec:480, useSpawnDelay, deathPenaltyMul:0.2}(引擎一等支持,usermission 抄不了)。
- 多出生点标准姿势: `missionMarkAsRespawnPoint{loc_name:"missions/airfield_spawn1..5"/"main_base",
  target:<机场实体>, team:A/B, isAirfield:yes, tags{air/helicopter/type_longrange_bomber/tank/ship 白名单}}`;
  核轰炸机走独立点(spawn_random/ground_spawn_south/north, isStrictPosAndDir);机场点 type_longrange_bomber:no。
- 机场系统: `airfieldSetProperties{enemySurrenderOnLanding}` + `missionSetBombingArea{use_variable, var_value:HP, airfield:实体}`
  + `missionIsBombingAreaDestroyed` → gameMPChangeScore 扣票; HP/tickets 均 descriptor 注入(main 200000/front 50000/-1000)。
- **权重分层**: `additionalEcsTemplates{ airfield_aa_1970{rankRange:ip2=0,30} 1980{31,36} 2018{37,50} }`
  挂在机场/阵地 objectGroups 上(部分四档 0-26/27-30/31-36/37-50;强据点等 0-50 不分);
  触发器级门控: `spawn_mlrs` conditions `varCompareInt{var_value:"mission_rank" value:30 comparasion_func:"more"}`
  (1970 无 MLRS)。mission_rank 来自 `missionGetBalanceLevel`。
- 敌方布防: 每队 5 前线机场+1 主机场、3 燃料库/3 弹药库/7 组装基地(轰炸目标)、8 强据点;
  MLRS×5/TBM×3(Tochka vs Lance)/预警雷达×3(AEW 55J6 vs TPS-59)= 触发单位,
  `unitRespawn{target:<spawn_area>, randomSpawn:yes}` 复活 600s(MLRS/TBM)/900s(雷达),
  每台有 6 个 `*_move` 区域随机点; SAM 短×5 长×3 `dyn_sam_site_wide_arragement`,守卫掩体 480s;
  航母×4、舰队×2、直升机坪 4/队; 核轰炸机从图外 `nuclear_strategic_bomber_spawn_40km` 进场。
