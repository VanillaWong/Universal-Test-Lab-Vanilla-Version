## 3. 投弹视角(bomber_view)调查 —— 引擎限制结论

**症状**:官方车库试驾、官方战斗/PvE 里轰炸机有"投弹视角";UTL HOT 任务里没有
(座舱 ✓ 机枪位 ✓ 能投弹 ✓,唯缺投弹视角)。

### 判定链(camera.blk)
```
config/camera.blk   ← 视角总表(aces.vromfs.bin 内;注意文件名是 camera.blk 不是 .blkx)
  bomber_view { type=BomberViewCamera, condition { isBomber && (hasBombguns || hasTorpedoes) } }
  weapon_aim_camera { type=WeaponAimCamera, condition { IsWeaponAimAllowedCondition } }
  cameraLists.plane { tps… bomber_view … weapon_aim_camera }
```
`isBomber` 数据源 = flightmodel 顶层 `type:t="typeBomber"`(Tu-4 有);
`hasBombguns` = 挂载含 `Weapons/BombGuns/*`(Tu-4 原生预设内嵌)。

### 官方配方(关键发现)
`mis.vromfs.bin → gamedata/missions/templates/player_unit_template.blk`:
```
armada {
  unit_class:t = "dummy_plane"      ← 占位,引擎运行时替换为客户端玩家机
  props { player:b = true; ... }    ← 官方玩家标志
}
```

### 实验矩阵(全部在热任务上手工改 + 用户游戏内实测)
| 配置 | 能进 | 投弹视角 |
|---|---|---|
| 自建类 `utl_run_*`(UTL 现状) | ✓ | ❌ |
| 自建类 + `player:b=yes`(注意是错值) | ✓ | ❌ |
| 自建类 + `player:b = true` | ✓ | ❌ |
| 官方类 `tu_4_(已解锁)` + `player:b = true` | ✓ | **✅** |
| 官方类 `yak_28b`(未解锁) + `player:b = true` | ❌ 卡住/要求购买 | — |
| `dummy_plane` + `player:b = true` | ❌ 要求购买(无机型信息) | — |
| 官方类名 + pkg_local 同名覆盖飞行模型 | (未走到) | ❌(引擎识破覆盖来源) |
| `changeUnit` 运行时换官方机 | ✓ | ❌ |

**结论**:投弹视角属于"引擎客户端玩家机"装配路径,仅当
`unit_class = 官方机型 id` + `player:b=true`,且**账号已解锁该机**时生效。
UTL 的自建类路线(为未解锁机型/自定义挂载)天然拿不到该视角。

### 待用户决策
- **A. 加「官方装配模式」开关**(推荐):勾选 → 玩家单位用官方类名 + `player:b=true`
  (+原生 preset 名),投弹视角正常;代价=需已解锁、挂载只能用原生方案。
  不勾 → 现状自建类(任意未解锁机可玩,无投弹视角)。
- **B. 保持现状**,视为引擎能力边界。
