## 4. 玩家开船（本轮重点）

### 4.1 机制（全部实测通过）

```
① 代理文件：content\pkg_local\gameData\units\ships\userVehicles\utl_naval_player.blk
     include "#/develop/gameBase/gameData/units/ships/<真实舰船>.blk"
② 任务单位：必须在 units{} 里作为 **ships{} 兄弟块**，不能嵌套在已有 ships{} 内
③ props：必须替换成舰船编队属性，不能沿用飞机的 plane{} / speed 1100
④ weapons:t = **单位 weapon_presets 里注册的名字**（不是 blk 文件名！）
⑤ bullets0..3:i = 9999（否则"弹药储备耗尽"）
⑥ crewSkillK = 1；applyAllMods = yes
```

### 4.2 代码位置

| 位置 | 作用 |
|---|---|
| `MainForm.LoadCatalogs`（MainForm.cs） | 舰船以 `Kind="Ship"` 并入载具列表；过滤 `_ai`/`typeShip` 与无预设船（602/663） |
| `BuildCustomShip`（Generate.cs） | 写代理文件，返回 classId/preset |
| `ResolveShipPreset`（Generate.cs） | 优先 UI 选择 → `<id>_default` → 第一个非 torpedoes 预设 |
| `ShipPresetNames`（BuildUi.cs） | 从单位文件 `weapon_presets{}` 读**注册名** |
| `ModificationsFor`（BuildUi.cs） | 舰船改装件从单位文件 `modifications{}` 现读（目录里没有） |
| `BlkTools.ConfigureShipPlayer` | 搬单位到 ships{}、换 props、换海图/出生点、写弹药槽 |
| `ModernFlightConfigureWindow`（Options.cs） | SHIP LOADOUT 卡片：预设 / 地图 / X-Z-Y |

### 4.3 踩过的坑（重要）

1. **单位块会带上容器头**：`UnitBlockByName` 返回 `"  armada{ ... }"`，搬迁时必须改写容器名，否则嵌套。
2. **嵌套 vs 兄弟**：第一次写成 `ships{ 靶船 … ships{ You } }`，任务能加载但玩家无船（一片空地）。
3. **飞机 props 残留**：`plane{}` + `speed:r=1100` 会让舰船摆不出来 → 必须整块替换。
4. **预设必须写注册名**：写文件名时引擎静默忽略，整套预设武器（含鱼雷）消失。
5. **弹药槽为 0** → "弹药储备耗尽"。
6. **改装件目录不含舰船**（`modifications.json` 只有飞机/坦克）→ 必须现读单位文件。
7. **`_ai` 变体**不可玩；37 艘 `_ec` 变体没有 `<id>_default` 预设。

## 5. 水深与海图

- 水深 = `water_level - 地形高度`，地形在 `.bin` 高度图里，**无法用参数直接加深**。
- 试过的办法：把 `pkg_user\levels\Clean_Testdrive.blk` 的 `water_level` 1→100 → 能潜，但**视觉很差**（整片地形淹成怪形状）。已回滚到 1.0，备份 `Clean_Testdrive.blk.bak_water`。
- 现在改为**官方海图**：`avn_blacksea_port` / `avn_fiji` / `avn_japan` / `avn_norway_islands` / `guadalcanal` / `saipan` / `avn_mediterranean_port`（客户端 `levels\*.bin`，公用资产）。
- CDK 的 `heightmapLand.plugin.blk` 里有 `minUnderwaterBottomDepth`（真正的水深参数），但需要 Dagor 重新导出关卡 → 未做。

## 7. 工具 / 环境备忘

- **改代码**：`code_execution` 写 Node 补丁脚本到沙箱 → `user_exec node <脚本>` 执行（绕开审批超时）。
  - 不要用括号计数定位方法体（字符串里也有 `{`）；用"下一个方法签名"做边界。
  - `Regex.Replace(str, pattern, repl, 1)` 不存在，必须 `new Regex(...).Replace(str, repl, 1)`。
  - commit message 里别用双引号（PowerShell 会把参数切断）。
- **编译**：`cmd /c compile.bat`，UTL 必须关闭；崩溃自测会留下**无窗口僵尸进程**，普通 `taskkill` 报 Access denied，需要任务管理器结束。
- **自测**：`dist\UniversalTestLab.exe --selftest`（含海军/机体/雷达断言）
- **数据重建**：`Update-Data.ps1` 约 25 分钟，需后台跑 + 轮询日志（单条命令 120s 上限）
- **Ask3lad 抓取**：`node tools/capture-ask3lad.js` → `captures/ask3lad-<时间戳>/report.txt`（diff 他的产物 vs 原生）
- **海军移植测试**：`node tools/make-naval-test.js --ship <id>`（依赖他的任务骨架，仅测试用）
